# BTC Contrakt - Bitcoin Mining Platform

Eine umfassende Web-Plattform für Cloud-Mining, Reward-Verteilung, Wallet-Anbindung und Hardware-Management.

## Features

- 🔐 **Cloud-Mining Management**: Verwalte Mining-Pools und Verträge
- 💰 **Reward-Verteilung**: Automatische Auszahlung und Tracking
- 🏦 **Wallet-Anbindung**: Integration mehrerer Bitcoin-Wallets
- ⚙️ **Hardware-Management**: Überwachen und verwalten von Mining-Hardware
- 📊 **Dashboard**: Echtzeit-Statistiken und Analysen
- 🔔 **Benachrichtigungen**: Alerts für wichtige Events

## Tech Stack

- Frontend: React 18 + TypeScript + Tailwind CSS
- Backend: Node.js + Express + MongoDB
- APIs: Web3.js für Blockchain-Integration

## Installation

```bash
npm install
npm run dev
```
